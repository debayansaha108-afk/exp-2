# Experiment 2 – Implement Custom Toast and Activity Lifecycle Methods

## 📌 Description

This experiment is developed using Android Studio as part of the Mobile Application Development Lab. It demonstrates the implementation of a custom Toast message and the understanding of Android Activity Lifecycle methods.

A custom Toast allows developers to display messages using a customized XML layout instead of the default Toast appearance. The Activity Lifecycle demonstrates how an Android Activity responds to different states during application execution.
