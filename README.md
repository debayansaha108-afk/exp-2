
# Experiment 2 – Implement Custom Toast and Activity Lifecycle Methods

An Android application developed using Android Studio and Kotlin as part of the Mobile Application Development Lab. This experiment demonstrates how to create a custom Toast message using a custom XML layout and understand Android Activity Lifecycle methods.

## 👨‍💻 Author

- Name: Debayan Saha
- Subject: Mobile Application Development Lab

## 🚀 Features

- Implements a custom Toast message.
- Uses a custom XML layout for the Toast interface.
- Demonstrates Android Activity Lifecycle methods.
- Uses Kotlin for application logic.
- Uses XML to design the user interface.
- Helps understand the lifecycle of an Android Activity.

## 🛠️ Technologies Used

- Android Studio
- Kotlin
- Java
- XML
- Android SDK
